# ibrahimsava.github.io

Portfolio d'Ibrahim Savadogo, ingénieur logiciel Full Stack (Java / Spring Boot, Angular, Flutter, Python / Django, data et IoT).

Site en ligne : https://ibrahimsava.github.io

## Contenu

- Page unique en HTML, CSS et JavaScript, sans dépendance ni étape de build.
- Bilingue français / anglais, thème clair et sombre, responsive.
- Métadonnées SEO, Open Graph et données structurées schema.org.
- Accessible : navigation au clavier, lien d'évitement, respect de `prefers-reduced-motion`.
